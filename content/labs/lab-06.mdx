<Step n={2} title="Part A · list.c (3 points)" time="25 min" id="part-a">

A linked list of numbers. Read numbers until the user types 0, inserting each one at the **head**; print the list; search it for a target; free every node.

<Terminal lines={['make list', './list']} out={`Number (0 to stop): 1
Number (0 to stop): 2
Number (0 to stop): 3
Number (0 to stop): 0
List: 3 2 1
Target: 2
Found`} />

The struct and the four prototypes are written for you. `insert_head` returns the new head, so `main` calls it as `list = insert_head(list, n);`. Inside, three lines, in this order: allocate the node and set its number, point its `next` at the old list, return the new node. `print_list` and `search` are the lecture's `for (node *ptr = list; ptr != NULL; ptr = ptr->next)` walk; print each number with a space in front. `free_list` is `list6.c`: remember `next` before you `free`.

Run `valgrind ./list` when it works. The checks do, and a forgotten `free_list` costs the whole part.

</Step>

<Step n={3} title="Part B · queue.c (2 points)" time="15 min" id="part-b">

A queue of names with room for four, driven by commands:

<Terminal lines={['make queue', './queue']} out={`> add Mario
> add Luigi
> next
Mario
> next
Luigi
> next
Empty
> quit`} />

`add NAME` enqueues (print `Full` if there is no room), `next` dequeues and prints the name (`Empty` if nobody is waiting). The struct keeps `front` and `size`; the next free slot is `(front + size) % CAPACITY`, and after a dequeue `front` moves to `(front + 1) % CAPACITY`. That `%` is what makes the array **circular**: after four adds and two removes there is room again at the beginning, and the tests check exactly that.

In `main`, `strncmp(cmd, "add ", 4) == 0` recognizes an add command, and `cmd + 4` is the name after it (pointer arithmetic from week 6, finally useful).

</Step>

<Step n={4} title="Part C · dictionary.c (5 points)" time="40 min" id="part-c">

Four functions that `speller.c` calls: `load`, `check`, `size`, `unload`. Start with the lecture's hash table exactly: `N = 26` buckets and `hash` returning the first letter as 0–25. Get it **correct** first, then make it **fast**.

<Terminal lines={['make speller', './speller dictionaries/small texts/cat.txt']} out={`
MISSPELLED WORDS

purrs

WORDS MISSPELLED:     1
WORDS IN DICTIONARY:  30
WORDS IN TEXT:        23
TIME IN load:         0.00
TIME IN check:        0.00
...`} />

- **load**: `fopen` the dictionary; read one word at a time with `fscanf(file, "%45s", buffer)` until it returns `EOF`; for each word, `malloc` a node, `strcpy` the word into it, prepend it to `table[hash(buffer)]` (two lines, same order as Part A), and count it; `fclose`; return `true`. Return `false` if the file does not open.
- **check**: walk the bucket `table[hash(word)]` and compare with `strcasecmp`, which ignores case, so that `Cat` and `cat` are both correct. Return `true` on a match.
- **size**: return the count from `load`.
- **unload**: free every node in every bucket, Part A's `free_list` inside a loop over the buckets; return `true`.

Test with the small dictionary and `texts/typos.txt` until the misspelled list is exactly the six typos (plus the ordinary words that the tiny dictionary simply does not know). Then run the referee: `valgrind ./speller dictionaries/small texts/cat.txt`.

Now make it fast. Run `./speller dictionaries/large texts/lecture.txt` and look at `TIME IN check`. With 26 buckets and a first-letter hash, each bucket holds thousands of words and every check walks a long list. Open the notebook, compare the three hash functions, then copy **djb2** into `dictionary.c` (three lines) and raise `N` to a few tens of thousands (`#define N 65536`). Run again and watch the time collapse. That difference is the whole point of the week.

> [!tip] Why `#define N 26` and not `const int N = 26`
> C needs a genuine constant for the size of a global array; a `const int` is a variable that happens not to change, and gcc refuses it. `#define` is text substitution, so `table[N]` becomes `table[26]` before the compiler even sees it. Keep the `#define` when you change the number.

</Step>

## Troubleshooting

> [!note] `Could not load dictionaries/small`
> `load` returned `false`. Check that you return `true` at the end, and that `fopen` got the exact path (`dictionaries/small`, no extension).

> [!note] Segmentation fault in `check` or `unload`
> A bucket that was never initialized, or walking past `NULL`. Global arrays start as `NULL` automatically; if you `malloc` the table yourself, initialize it. Every walk stops at `ptr != NULL`.

> [!note] WORDS IN DICTIONARY is 0
> `size` returns 0: count the words in `load` and return that counter.

> [!note] Correct words are reported as misspelled
> Your `check` compares with `strcmp` (case-sensitive) or hashes `Cat` and `cat` into different buckets. Use `strcasecmp`, and make the hash lowercase every letter before it uses it.

> [!note] `error: variably modified 'table' at file scope`
> You turned the `#define N` back into a variable. See the tip in Part C.

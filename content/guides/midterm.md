## What it covers

Weeks 1–7, the C part of the course: representation, algorithms, C, arrays and strings, searching and sorting, memory, and data structures. **Python (week 8 onward) is not on the midterm.** Everything on this site from [week 1](/weeks/week-01) to [week 7](/weeks/week-07) is fair game; the [lab](/labs) programs are the best predictor of the coding questions.

## Format

- One hour, written, on paper. Bring a pen and your student ID. No notes, no devices.
- Roughly: 30% short answers (representation, definitions, Big O), 40% code tracing and memory diagrams, 30% writing short C functions.
- You will trace code, draw memory, write short C functions and explain trade-offs, without a compiler.

## How to review

1. **One page per week.** Write the key ideas of each week on one sheet, by hand. If it does not fit, you do not yet know what matters.
2. **Redo, do not reread.** Open a blank file and rewrite Lab 2's calculator, Lab 3's cipher, Lab 4's binary search, Lab 5's swap and Lab 6's linked list from memory. Compile them. That is the exam, with a compiler.
3. **Trace on paper.** Take three short programs from the CS50 notes and write their output without running them. Then run them.
4. **Explain to someone.** Pointers, hash tables and Big O to a friend who is not in the course. If they get it, so do you.

## Checklist by week

| Week | You should be able to |
|---|---|
| 1–2 | Convert between binary, decimal and hexadecimal; explain ASCII, Unicode and RGB; describe an algorithm's steps |
| 3 | Trace a C program with variables, conditions, loops and functions; explain types, overflow and float imprecision |
| 4 | Work with arrays and strings in C: `\0`, `strlen`, command-line arguments, exit codes |
| 5 | Compare algorithms with Big O; trace linear and binary search, selection, bubble and merge sort; recursion |
| 6 | Draw memory for pointer code; explain `swap`, `malloc`/`free`, segfaults and leaks; what valgrind reports |
| 7 | Implement linked-list operations; explain stacks, queues, hash tables, trees, tries and when to use each |

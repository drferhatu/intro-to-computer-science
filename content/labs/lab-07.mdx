<Terminal lines={['python caesar.py 13']} out={`plaintext:  HELLO, world

<Terminal lines={['python caesar.py', 'echo $?']} out={`Usage: python caesar.py key

Rules, the same as the C version: exactly one argument, digits only, otherwise print `Usage: python caesar.py key` and `sys.exit(1)`; rotate by `key % 26`; keep the case; leave punctuation, digits and spaces alone; prompt `plaintext:  ` (two spaces, so the two lines align) and print `ciphertext: ` followed by the result.

`sys.argv` is `argv` as a list: `len(sys.argv) != 2` replaces `argc != 2`, and `sys.argv[1].isdigit()` replaces the loop that checked every character. In `rotate`, `ord(c)` gives the ASCII code and `chr(n)` turns one back into a character, so an upper-case letter becomes `chr((ord(c) - ord("A") + key) % 26 + ord("A"))`; `c.isupper()` and `c.islower()` decide which alphabet. Build the result character by character, either with a loop and `+=` or in one line with `"".join(rotate(c, key) for c in plaintext)`.

</Step>

- **load**: open the file with `with open(dictionary) as file:` and put every line into the set: `words.update(file.read().splitlines())`. Return `True`. If the file does not exist, `open` raises `FileNotFoundError` (an `OSError`): catch it and return `False`, which is what the last test checks.

- **size**: `len(words)`.
- **unload**: there is no memory to free; `words.clear()` and `return True`.

## Troubleshooting

> [!note] `IndentationError` or `unexpected indent`
> Python blocks are made of indentation. Every line inside a `def`, `if`, `for` or `while` must be indented by the same amount (four spaces); mixing tabs and spaces fails. VS Code's *Format Document* (Shift+Alt+F) fixes most of it.

> [!note] `NameError: name 'sys' is not defined`
> You used `sys.argv` without `import sys` at the top of the file.

> [!note] `ValueError: invalid literal for int()`
> `int("cat")`. Wrap the conversion in `try:` / `except ValueError:`; Part A is about exactly that.

> [!note] Part A re-prompts forever on a valid number
> The `break` is missing, or it is inside the `except` instead of after the range check. Order: convert, then check `1 <= height <= 8`, then `break`.

> [!note] `caesar.py` says Usage for `python caesar.py 13`
> You checked `len(sys.argv) != 1`. The program name is `sys.argv[0]`, so with one key the length is 2, as in C.

> [!note] WORDS IN DICTIONARY is 0, or `Could not load`
> `load` returned `False` or never filled the set. Return `True` at the end, and make sure `words` is the module-level set, not a new local variable (`words = set()` inside `load` creates a different one; use `words.update(...)`).

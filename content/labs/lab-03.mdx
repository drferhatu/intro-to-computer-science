The three functions are declared for you: `lowest`, `highest` and `average`, each taking the length and the array, exactly like `average(int length, int array[])` in the lecture's `scores5.c`. Fill them in, then complete `main`.

Two things to notice. First, `int scores[n];` after reading `n` is allowed in C: the size does not have to be a constant. Second, the smallest value in an array is found by assuming the first element is the smallest and then letting every other element challenge it; the same with the largest.

<Step n={4} title="Part B · readability.c (3 points)" time="25 min" id="part-b">

Read a text and print the U.S. school grade needed to read it, with the **Coleman–Liau index**:

```text
index = 0.0588 × L − 0.296 × S − 15.8
```

where **L** is the average number of letters per 100 words and **S** the average number of sentences per 100 words. Round the index to the nearest whole number; print `Before Grade 1` if it is below 1, `Grade 16+` if it is 16 or more, otherwise `Grade N`.

<Terminal lines={['make readability', './readability']} out={`Text: Congratulations! Today is your day. You're off to Great Places! You're off and away!
Grade 3`} />

Counting rules, the same as CS50's: a **letter** is anything for which `isalpha` is true; **words** are separated by single spaces, so the number of words is the number of spaces plus one; a **sentence** ends with `.`, `!` or `?`. Write the three counting functions first and test each with a `printf` before you compute the index. For the example above you should count 65 letters, 14 words and 4 sentences.

> [!tip] Two traps
> `letters / words` with two ints truncates to 0; cast first, `letters / (float) words * 100`. And `round` lives in `<math.h>`, which is already included and already linked for you.

</Step>

<Step n={5} title="Part C · caesar.c (4 points)" time="25 min" id="part-c">

A Caesar cipher whose key comes from the command line:

<Terminal lines={['make caesar', './caesar 13']} out={`plaintext:  HELLO, world
ciphertext: URYYB, jbeyq`} />

The rules, in the order you should implement them:

1. **Validate.** Exactly one argument, made only of digits. Otherwise print `Usage: ./caesar key` and `return 1`. `only_digits` is declared for you; `isdigit` from `<ctype.h>` checks one character. Test it before anything else: `./caesar`, `./caesar 1 2`, `./caesar abc` must all print the usage line, and `echo $?` must show `1`.
2. **Convert** the key with `atoi(argv[1])` from `<stdlib.h>`.
3. **Read** the plaintext with `get_string("plaintext:  ")`, print `ciphertext: `, then every character passed through `rotate`.
4. **Rotate.** An uppercase letter's position is `c - 'A'`; add the key, take `% 26`, add `'A'` back. The same with `'a'` for lowercase. Anything that is not a letter is returned unchanged. Keys larger than 26 must work; `% 26` takes care of that.

<Terminal lines={['./caesar 3', './caesar 27']} out={`plaintext:  xyz XYZ
ciphertext: abc ABC
plaintext:  abc
ciphertext: bcd`} />

Encrypt something with 13, then encrypt the result with 13 again. You get the original back; ROT13 is its own inverse, and the notebook below shows why.

</Step>

## Challenges (optional, not graded)

1. **Decrypt.** Add a second argument, `./caesar 13 -d`, that shifts backwards. Careful with negative remainders in C.
2. **Vigenère.** Instead of one key, a keyword: `./vigenere lemon` shifts the first letter by `l`, the second by `e`, and so on, skipping non-letters.
3. **Reading levels in Turkish.** Coleman–Liau was tuned for English. Run `readability` on a Turkish paragraph and think about why the grade is off: what counts as a sentence, and how long Turkish words are.

## Troubleshooting

> [!note] `undefined reference to round`
> Compile with the math library: `gcc -o readability readability.c cs50.c -lm`. `make readability` and the tests already do this.

> [!note] My Caesar output has strange characters
> You added the key to the character without wrapping, or wrapped before subtracting `'A'`. The order is: subtract the base letter, add the key, `% 26`, add the base letter back.

> [!note] `./caesar` with no argument crashes instead of printing the usage line
> You read `argv[1]` before checking `argc`. The check must come first; `argv[1]` does not exist when `argc` is 1.

> [!note] Readability is off by one grade
> Check the word count on the example sentence (14) and the letter count (65); apostrophes are not letters and `isalpha` already knows that. Then check that you divide with a cast and `round` the final index, not L or S.

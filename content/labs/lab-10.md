## Plan

This lab opens in week 12. The full step-by-step page, the starter repository and the tests are published before that Monday; the plan below is final.

1. **index.html**: a valid page with headings, a list, an image, a link and a form with at least three input types.
2. **style.css**: an external stylesheet with classes, flexbox layout and a responsive rule.
3. **script.js**: a click counter, live form validation and a greeting that uses the form's value, all without reloading.
4. **Publish**: enable GitHub Pages on your lab repository and paste the URL in the README.
5. **Explore**: last year's five interactive examples, forked and modified.

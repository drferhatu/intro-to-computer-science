## From blocks to text

Last week's five ideas, in text. The cost: you can now make syntax errors, and the compiler will tell you about every one of them. The gain: you can write anything, and the result runs on every computer on Earth.

```c
#include <stdio.h>

int main(void)
{
    printf("hello, world\n");
}
```

| Piece | Meaning |
|---|---|
| `#include <stdio.h>` | Use the standard input/output library, which is where `printf` lives. Like importing a Scratch extension. |
| `int main(void)` | The program starts here. The green flag. |
| `{ … }` | A block: the statements that belong to `main`. |
| `printf("hello, world\n");` | Call the function `printf` with one argument. `\n` is a newline. The `;` ends the statement. |

## Source code → machine code

The processor understands only bits, so your text must be translated. That is the **compiler**'s job.

<Terminal lines={['code hello.c', 'make hello', './hello']} out="hello, world" />

`make hello` is a convenience: it really runs `clang -o hello hello.c` (plus `-lcs50` when you use the CS50 library). Three steps you will repeat a thousand times: **edit, compile, run**. When the compiler complains, read the *first* error, fix it, compile again. Most later errors are echoes of the first.

> [!note] Correctness, design, style
> CS50 grades code on three axes. **Correct**: does it do what it should? **Design**: is it written well, without needless repetition? **Style**: is it readable, consistently indented, sensibly named? The autograder checks the first; the instructor looks at the other two in your project.

## Variables and types

C wants to know what kind of value a variable holds, because different kinds take different numbers of bytes.

| Type | Holds | Bytes | Example |
|---|---|---|---|
| `int` | integers | 4 | `int age = 19;` |
| `long` | bigger integers | 8 | `long population = 8000000000;` |
| `float` | real numbers, ~7 digits | 4 | `float pi = 3.14159;` |
| `double` | real numbers, ~15 digits | 8 | `double e = 2.718281828459045;` |
| `char` | one character | 1 | `char grade = 'A';` |
| `bool` | true / false | 1 | `bool done = false;` (needs `<stdbool.h>` or `<cs50.h>`) |
| `string` | text (CS50 library) | pointer | `string name = "Alice";` (needs `<cs50.h>`) |

`=` is **assignment**, not equality. `int x = 5;` creates `x` and puts 5 in it. `x = x + 1;` (or `x++;`) puts the old value plus one back. Equality is `==`.

### Output with printf

`printf` prints a **format string** where placeholders are replaced by values:

```c
int age = 19;
float gpa = 3.75;
char initial = 'F';
string name = "Firat";
printf("%s is %i, initial %c, GPA %.2f\n", name, age, initial, gpa);
```

`%i` int, `%f` float/double (`%.2f` two decimals), `%c` char, `%s` string, `%li` long, `%%` a literal percent sign.

### Input with the CS50 library

```c
#include <cs50.h>
#include <stdio.h>

int main(void)
{
    string name = get_string("What's your name? ");
    printf("hello, %s\n", name);
}
```

`get_string`, `get_int`, `get_float`, `get_long`, `get_char` ask the user and **return** a value. They re-prompt on nonsense; you still have to reject values that are the wrong *size*, which is what loops are for. In week 6 we look inside `get_string`; for now it is an abstraction, like a Scratch block.

## Conditions

```c
if (x < y)
{
    printf("x is less than y\n");
}
else if (x > y)
{
    printf("x is greater than y\n");
}
else
{
    printf("x is equal to y\n");
}
```

Comparison operators: `<`, `<=`, `>`, `>=`, `==`, `!=`. Logical: `&&` (and), `||` (or), `!` (not). Parentheses are required around the condition, and the condition is a **boolean expression**: something true or false.

> [!warning] The most common bug in C
> `if (x = 5)` **assigns** 5 to x and is always true. You meant `if (x == 5)`. Compilers warn about this; read the warning.

## Loops

```c
// while: repeat as long as the condition holds
int i = 0;
while (i < 3)
{
    printf("meow\n");
    i++;
}

// for: the same, with init, condition and update in one line
for (int i = 0; i < 3; i++)
{
    printf("meow\n");
}

// do-while: run once, then check. Perfect for input validation.
int n;
do
{
    n = get_int("Positive number: ");
}
while (n < 1);
```

Use `for` when you know how many times; `while` when you repeat until something happens; `do … while` when the body must run at least once. `while (true)` with a `break` inside is the "forever" block.

## Functions

Scratch's *make a block* is a **function** in C:

```c
#include <stdio.h>

void meow(int n);          // prototype: tell the compiler it exists

int main(void)
{
    meow(3);
}

void meow(int n)           // definition
{
    for (int i = 0; i < n; i++)
    {
        printf("meow\n");
    }
}
```

`void` means "returns nothing". A function can also **return** a value:

```c
int square(int x)
{
    return x * x;
}
```

Functions are the unit of **abstraction**: once `meow` works, `main` reads like English. The prototype is needed because C reads top to bottom and `main` calls `meow` before `meow` is defined.

> [!definition] Scope
> A variable exists only inside the braces where it was declared. `int i` in a `for` loop is gone after the loop. This is why functions cannot see each other's variables, and why we pass **arguments** and get **return values**.

## Where numbers break

### Integer overflow

An `int` is 32 bits: 4 294 967 296 values, split into −2 147 483 648 … 2 147 483 647. Add one to the maximum and the bits wrap around to the minimum, like a car odometer. That is the 787 bug in the wow moment, and the reason YouTube once had to change its view counter to a `long` when *Gangnam Style* passed 2³¹ views.

```c
int big = 2147483647;
big = big + 1;
printf("%i\n", big);      // -2147483648
```

Use `long` when values can be large, and think about the maximum whenever you count anything.

### Floating-point imprecision

```c
float x = 1.0;
float y = 10.0;
printf("%.20f\n", x / y);  // 0.10000000149011611938
```

0.1 has no exact binary representation, just as ⅓ has no exact decimal one. A `float` keeps about 7 significant digits, a `double` about 15. Never compare floats with `==`; never store money in a float (banks use integers of cents).

## Summary

- Edit, compile (`make`), run (`./program`). Read the first compiler error.
- Types: `int`, `long`, `float`, `double`, `char`, `bool`, `string`. `printf` with `%i %f %c %s`.
- `get_int` and friends for input; `do … while` to validate it.
- `if / else if / else`, `while`, `for`, `do … while`, and your own functions with prototypes.
- Integers overflow, floats are approximate, and both have crashed real systems.
